# ⚽ Liga Familiar FC26

Visualizador moderno de estadísticas para los torneos familiares de FC25, ahora disponible como **Aplicación Web Progresiva (PWA)**.

------------------------------------------------------

## 🧩 Descripción

Este proyecto muestra de forma visual y moderna las estadísticas que los primos registran en un **Google Sheet** sobre sus torneos de liga de FC25.

En lugar de revisar datos crudos en la hoja de cálculo, esta app ofrece una tabla elegante, ordenada y fácil de leer.

Cada vez que se actualiza el Google Sheet, la app refleja los cambios automáticamente.

------------------------------------------------------

## 👥 Usuarios

Aplicación privada de uso familiar (solo primos).

------------------------------------------------------

## 📊 Fuente de datos

Los datos provienen directamente de un archivo de **Google Sheets** publicado como CSV.  
No se planea cambiar la fuente de datos ni utilizar una base de datos tradicional.

------------------------------------------------------

## ✨ Características

- Ordenar columnas con un clic  
- Resaltar la columna seleccionada  
- Logos dinámicos según equipo  
- Diseño moderno con fondo degradado  
- Tablas responsivas  
- Carga de datos en tiempo real desde Google Sheets  
- **Instalable como aplicación (PWA)**  
- Funciona sin backend (solo frontend)

------------------------------------------------------

## 📱 Progressive Web App (PWA)

La aplicación puede instalarse en:

- 📱 Teléfonos Android
- 💻 Escritorio (Chrome, Edge, Brave)

Una vez instalada:
- Se comporta como una app nativa
- Abre en pantalla completa
- Puede fijarse en el inicio o escritorio

> ⚠️ Actualmente **no incluye notificaciones push**.

------------------------------------------------------

## 🚀 Cómo usarla

1. Abre la URL del proyecto  
2. (Opcional) Instala la app desde el navegador  
3. Consulta las estadísticas actualizadas

------------------------------------------------------
